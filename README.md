# Bedroom render

Interactive 3D plan of my bedroom makeover, built with three.js. Drag to orbit, pinch or scroll to zoom. All measurements are in cm.

## What's in it

- **Room:** 370 × 345cm, 240cm ceiling, 15cm white skirting, five-panel curved bay window
- **Shelf wall (corner to door, 270cm):**
  - 100cm black mirror-door wardrobe (PAX, 58cm deep) in the window corner
  - 130cm TV section with lit cubbies above and below a wall-mounted 48" OLED (opening 85cm tall)
  - 40cm BILLY figure tower (237cm tall) next to the door
- **Desk wall:** 180cm desk with a two-katana rack above it, double bed with three 40 × 55cm canvases above the headboard
- **Radiator:** about 100cm along the wall beside the bed

## Files

- `index.html`: the full-screen site (no build step)
- `bedroom_3d_with_measurements_radiator_skirting.html`: the original export

## Run locally

Open `index.html` in a browser.
